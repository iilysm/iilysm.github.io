Cybersecurity CTF-Plattform

A Capture The Flag (CTF) challenge designed to deliver multi-stage web application and networking security challenges. This project bridges full-stack development with security engineering, offering hands-on experience in building virtual environments.

Architecture & Implementation
I architected a 3-VM Vagrant network environment to reliably deliver multi-stage networking security challenges. This approach ensures that challenge instances are reproducible and portable across systems.

At the application level, I developed a Django front-& backend to host the web security challenges. The platform provides an engaging way to practice and learn offensive security techniques.

Key features and skills:

  • Utilized Vagrant and Bash to provision a complex 3-VM network topology for realistic security scenarios.

  • Built the core platform using Python, Django, HTML, and CSS, incorporating a robust backend to handle challenge state and user validation.

  • Designed custom challenges focusing on networking and web vulnerabilities to foster practical learning.
Technical Details
  • Platform: Web, Virtual Machines
  • Languages: Python, Bash, HTML/CSS
  • Framework: Django
  • Tools: Vagrant, Git
