Cybersecurity CTF Platform

An interactive, multi-stage Capture The Flag (CTF) challenge that seamlessly bridges application security and network security. The best part: The entire project is bundled as a compact "Infrastructure as Code" package. Students can simply download the project as a ZIP file, spin it up locally via Vagrant with a single command, and start hacking immediately.

The Challenge Flow: From Web to Network
The challenge is designed as a realistic, multi-tiered attack scenario:

  • Application Security (Entry Point): Players start on a custom-built Django web application where they must identify and exploit modern web vulnerabilities.
  • Network Security (Transition): A successful web exploit serves as the gateway to the command line (CLI). From there, players dive deeper into the isolated VM network, using tools like Nmap to scan and compromise further targets.

Architecture & Implementation
To safely isolate the network security challenges, I designed a virtual 3-VM network topology using Vagrant. This ensures the infrastructure is fully reproducible, portable, and cross-platform without requiring complex local setups.

Key Features:

  • Plug & Play Design: Fully pre-configured multi-VM environment for an instant start via Vagrant.
  • Full-Stack Core: Independent platform built with Python, Django, HTML, and CSS to host the web security challenges.
  • Hands-on Offensive Security: Explores the chaining of digital attacks (Web Exploitation & Network Scanning).
Technical Details
  • Platform: Web, Virtual Machines (Multi-VM Topology)
  • Languages: Python, Bash, HTML/CSS
  • Framework: Django
  • Tools: Vagrant, Nmap, Git
