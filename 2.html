VR Navigation & Agile Workflow

Developed as part of a Human-Computer Interaction (HCI) research module, this project explores user navigation within virtual spaces. The result is a VR escape-room experience on the Meta Quest 3 that utilizes diegetic navigation cues—such as dynamic "ant-trails" and compasses—to guide users through complex spatial puzzles.

Project Management & Pipeline
As the Scrum Master for a team of three, I bridged the gap between creative design and technical implementation. I coordinated our sprint goals using Jira (Scrum) and established a Git workflow that allowed us to collaborate efficiently without stepping on each other's code.

To keep our repository clean, I introduced a weekly integration protocol we internally dubbed "Merge Mondays." This routine helped us resolve merge conflicts early and ensured our main branch remained stable for regular testing.

Narrative & NPC Logic
I was responsible for the design and technical implementation of "Gary," a companion NPC driven by a custom state machine. This system managed the character's lifecycle, orchestrating his spawn points and triggering context-sensitive dialogue based on the player's real-time progress through the escape room.

To influence user pacing and immersion, I also composed and implemented the original soundtrack (listen below).

Key Technical Implementations:

  • Navigation Systems: Implemented multiple pathfinding tools using Unity's navigation mesh, including a dynamic visual trail and an expandable minimap UI.

  • UI/UX Experimentation: Designed a "Dark Mode" challenge variant. This timed mode features increased intensity and satirizes modern dark-mode interfaces, serving as a test for user efficiency under visual pressure.

  • Interactive Storytelling: Built a state-machine driven narrative structure that guides the player from the initial puzzle to a cinematic ending sequence.
