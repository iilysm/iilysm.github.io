    Spotify Data Analysis: Predicting Chart Success

    Developed during my exchange semester in Japan, this project combines my growing interest in music technology with data science fundamentals.

    The Objective
    We sought to determine if a song's commercial success could be predicted by its intrinsic audio qualities. I utilized a Kaggle dataset of 2023’s most streamed songs, enriched with metadata from the Spotify Audio Features API.

    Data Pipeline & Exploration
    I implemented a data cleaning workflow to handle malformed entries and encode categorical variables. Using exploratory visualization techniques, I mapped out correlations to prepare the dataset for Linear Regression modeling.

    Critical Analysis
    We trained three regression models to evaluate the dataset's predictive power. The results highlighted significant limitations in both the data and the metrics:

    • The Limits of Aggregated Features: Models trained exclusively on API metrics (e.g., 'danceability', 'energy') failed to predict stream counts. These low-dimensional, reductive numbers cannot capture the cultural context or perceived quality that actually drives human engagement.

    • The "Chicken-and-Egg" Problem: While cross-platform playlist presence was the strongest mathematical predictor, we identified this as a circular correlation. Popularity forces songs onto playlists, and playlists enforce popularity. The model essentially mapped the platform's amplification loop rather than uncovering a formula for a hit.

    Conclusion & Industry Outlook
    While our model struggled using public metadata, we hypothesize that chart success is predictable—but it requires access to high-fidelity, proprietary data (such as raw audio signal processing or granular user retention logs) that is currently locked away.

    The recent closure of the Spotify Audio Features API (Nov 2024) underscores this shift. Originally designed to let third-party developers visualize "taste profiles," these datasets became inadvertent fuel for AI training. The industry's move to deprecate these public endpoints signals the end of the open-data era; user data is no longer a shared utility for insights, but a guarded asset in the age of generative AI.
