    Ανάλυση Δεδομένων Spotify: Πρόβλεψη Επιτυχίας στα Charts

    Αναπτύχθηκε κατά τη διάρκεια του εξαμήνου ανταλλαγής μου στην Ιαπωνία, αυτό το έργο συνδυάζει το αυξανόμενο ενδιαφέρον μου για τη μουσική τεχνολογία με τις βασικές αρχές της επιστήμης δεδομένων.

    Ο Στόχος
    Επιδιώξαμε να προσδιορίσουμε εάν η εμπορική επιτυχία ενός τραγουδιού θα μπορούσε να προβλεφθεί από τις εγγενείς ηχητικές του ποιότητες. Χρησιμοποίησα ένα σύνολο δεδομένων Kaggle με τα τραγούδια με τις περισσότερες ροές του 2023, εμπλουτισμένο με μεταδεδομένα από το Spotify Audio Features API.

    Διοχέτευση Δεδομένων & Εξερεύνηση
    Εφάρμοσα μια ροή εργασίας καθαρισμού δεδομένων για τον χειρισμό κακοσχηματισμένων καταχωρήσεων και την κωδικοποίηση κατηγορικών μεταβλητών. Χρησιμοποιώντας διερευνητικές τεχνικές οπτικοποίησης, χαρτογράφησα συσχετίσεις για να προετοιμάσω το σύνολο δεδομένων για μοντελοποίηση Γραμμικής Παλινδρόμησης.

    Κριτική Ανάλυση
    Εκπαιδεύσαμε τρία μοντέλα παλινδρόμησης για να αξιολογήσουμε την προγνωστική ισχύ του συνόλου δεδομένων. Τα αποτελέσματα ανέδειξαν σημαντικούς περιορισμούς τόσο στα δεδομένα όσο και στις μετρήσεις:

    • Τα Όρια των Συγκεντρωτικών Χαρακτηριστικών: Μοντέλα που εκπαιδεύτηκαν αποκλειστικά σε μετρήσεις API (π.χ. «χορευτικότητα», «ενέργεια») απέτυχαν να προβλέψουν τον αριθμό των ροών. Αυτοί οι χαμηλής διάστασης, αναγωγικοί αριθμοί δεν μπορούν να συλλάβουν το πολιτιστικό πλαίσιο ή την αντιληπτή ποιότητα που πραγματικά οδηγεί την ανθρώπινη δέσμευση.

    • Το Πρόβλημα της "Κότας και του Αυγού": Ενώ η παρουσία σε λίστες αναπαραγωγής πολλαπλών πλατφορμών ήταν ο ισχυρότερος μαθηματικός προγνωστικός δείκτης, το αναγνωρίσαμε αυτό ως κυκλική συσχέτιση. Η δημοτικότητα αναγκάζει τα τραγούδια να μπουν σε λίστες αναπαραγωγής και οι λίστες αναπαραγωγής επιβάλλουν τη δημοτικότητα. Το μοντέλο ουσιαστικά χαρτογράφησε τον βρόχο ενίσχυσης της πλατφόρμας αντί να αποκαλύψει μια φόρμουλα για μια επιτυχία.

    Συμπέρασμα & Προοπτικές Βιομηχανίας
    Ενώ το μοντέλο μας δυσκολεύτηκε χρησιμοποιώντας δημόσια μεταδεδομένα, υποθέτουμε ότι η επιτυχία στα charts είναι προβλέψιμη — αλλά απαιτεί πρόσβαση σε ιδιόκτητα δεδομένα υψηλής πιστότητας (όπως επεξεργασία ακατέργαστου σήματος ήχου ή λεπτομερή αρχεία διατήρησης χρηστών) που είναι επί του παρόντος κλειδωμένα.

    Το πρόσφατο κλείσιμο του Spotify Audio Features API (Νοέμβριος 2024) υπογραμμίζει αυτή τη στροφή. Αρχικά σχεδιασμένα για να επιτρέπουν σε τρίτους προγραμματιστές να οπτικοποιούν "προφίλ γούστου", αυτά τα σύνολα δεδομένων έγιναν ακούσια καύσιμο για την εκπαίδευση AI. Η κίνηση της βιομηχανίας να καταργήσει αυτά τα δημόσια τελικά σημεία σηματοδοτεί το τέλος της εποχής των ανοιχτών δεδομένων. Τα δεδομένα χρήστη δεν είναι πλέον ένα κοινόχρηστο εργαλείο για πληροφορίες, αλλά ένα φυλασσόμενο περιουσιακό στοιχείο στην εποχή της παραγωγικής τεχνητής νοημοσύνης.
