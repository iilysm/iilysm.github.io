Flappy Speaker: Foundations in Game Dev & Modding

Completed as part of Harvard's online course GD50 (Introduction to Game Development), this project marks my initial step into structured software engineering. The core challenge was to deconstruct an existing, Lua-based implementation of Flappy Bird within the LÖVE 2D framework and creatively transform it through modding.

Transitioning from an analytical user to a hands-on developer required a deep dive into an unfamiliar codebase. By analyzing the game's architecture, I identified key variables and manipulated real-time physics parameters like gravity, velocity, and collision detection boundaries. Beyond the logical code level, I executed a visual overhaul using GIMP: a distinctive purple pixel art theme that replaced the classic bird with a speaker and the pipes with burning CDs. This early experience of merging design with technical logic sparked my passion for system modification and reverse engineering.

Technical Details
  • Platform: PC (LÖVE 2D Framework)
  • Language: Lua
  • Context: Harvard GD50 (Introduction to Game Development)
  • Tools: GIMP, LÖVE 2D
