Flappy Speaker: Foundations in Game Dev & Modding

As one of my earliest formal introductions to software development, this project was completed for Harvard's online GD50 (Introduction to Game Development) course. The core task was to deconstruct and creatively modify an existing LÖVE 2D (Lua) implementation of Flappy Bird (based on Colton Ogden’s port of Dong Nguyen's original).

Motivation & First Steps
This project served as my first practical opportunity to act on a long-standing interest in software modification, bridging the gap from being an analytical user to a hands-on developer. It served as a foundational experience in understanding how to dissect an existing codebase, identify key variables, and inject personal creativity into a pre-built system.

My main technical challenge was diving into the existing Lua codebase. I analyzed the game's structure to identify and modify key variables, allowing me to directly tweak physics parameters like gravity and velocity. A key part of the process was adjusting the bounding box rules to fine-tune the collision detection for my new, custom-designed assets. This technical foundation supported a complete creative reskin, for which I designed original pixel art in GIMP—replacing the bird with an audio speaker and the pipes with flaming CDs—and established a distinct "purple" visual theme. While a small-scale mod, this early experience of blending creative expression with technical logic was a key motivator for the path I've pursued since.

Key modifications and skills:

  • Asset Creation: Designed and implemented all-new pixel art graphics (GIMP) and custom sound effects to build a unique theme.

  • Physics & Gameplay Tuning: Directly edited Lua scripts to alter core gameplay variables, including gravity, player velocity, and level pacing.

  • Code Deconstruction: Analyzed the existing codebase to understand state management (e.g., 'start', 'play', 'game over' states) and collision detection logic.
Technical Details
  • Platform: PC (LÖVE 2D Framework)
  • Language: Lua
  • Context: Harvard GD50 (Intro to Game Development)
  • Tools: GIMP, LÖVE 2D
