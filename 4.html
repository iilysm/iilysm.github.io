Flappy Speaker: Foundations in Game Dev & Modding

Completed as part of Harvard's online course GD50 (Introduction to Game Development), this project marks my very first formal step into software engineering. The core challenge was to deconstruct an existing, Lua-based implementation of Flappy Bird within the LÖVE 2D framework and creatively transform it through modding.

Code Deconstruction & System Modification
This project allowed me to bridge the gap between being an analytical user and becoming a hands-on developer. The main technical challenge was diving deep into an unfamiliar codebase. By analyzing the game's architecture, I identified key variables, giving me direct control to manipulate real-time physics parameters like gravity, velocity, and game speed. I also adjusted bounding box rules to fine-tune collision detection for my custom assets.

Creative Reskin & Game Design
Beyond the source code adjustments, I executed a complete visual and auditory overhaul. Using GIMP, I designed a distinctive purple pixel art theme, replacing the classic bird with a speaker and the pipes with burning CDs. Merging creative expression with rigid technical logic and a "hacker mindset" during this project was a defining milestone that fueled my passion for computer science.

Key Modifications & Skills:

  • Code Analysis: Dissected an established codebase to master state management (e.g., 'Start', 'Play', 'Game Over' phases) and core game logic.
  • Physics & Gameplay Tuning: Direct scripting in Lua to modify environmental variables and pixel-perfect collision boundaries.
  • Asset Creation: Created and technically integrated brand-new pixel art textures (via GIMP) and custom sound effects to build a cohesive theme.
Technical Details
  • Platform: PC (LÖVE 2D Framework)
  • Language: Lua
  • Context: Harvard GD50 (Introduction to Game Development)
  • Tools: GIMP, LÖVE 2D
