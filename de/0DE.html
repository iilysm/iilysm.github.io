Backend-Implementierung in Django

Flag für die zweite Application-Challenge

Cybersecurity CTF-Plattform

Eine interaktive, mehrstufige Capture-The-Flag (CTF) Challenge, die Application Security und Network Security nahtlos verbindet. Das Highlight: Das gesamte Projekt ist als kompaktes "Infrastructure as Code"-Paket geschnürt. Studierende können die Challenge einfach als ZIP-Datei herunterladen, via Vagrant mit einem einzigen Befehl lokal starten und direkt loslegen.

Der Challenge-Flow: Vom Web ins Netzwerk
Die Challenge führt die Spieler durch ein realistisches, mehrstufiges Angriffsszenario:

  • Application Security (Einstieg): Spieler starten auf einer von mir entwickelten Django-Webanwendung, auf der sie klassische Web-Schwachstellen aufspüren und ausnutzen müssen.
  • Network Security (Übergang): Der erfolgreiche Web-Exploit dient als Sprungbrett in die Kommandozeile (CLI). Von dort aus analysieren und penetrieren die Spieler mittels Nmap ein isoliertes, VM-basiertes Netzwerk.

Architektur & Implementierung
Um die Netzwerk-Sicherheitsherausforderungen sicher zu isolieren, habe ich eine virtuelle Umgebung mit 3 VMs über Vagrant entworfen. Dieser Ansatz stellt sicher, dass die gesamte Infrastruktur reproduzierbar, portabel und plattformübergreifend ohne komplexe lokale Konfiguration läuft.

Wichtige Features:

  • Plug & Play für Studierende: Vollständig vorkonfiguriertes Multi-VM-Netzwerk für den sofortigen Start via Vagrant.
  • Full-Stack-Kern: Eigenständige Plattform mit Python, Django, HTML und CSS zur Bereitstellung der Web-Security Challenges.
  • Praxisnahe Offensive Security: Vermittelt das Verständnis für die Verkettung von Angriffen (Web Exploitation & Network Scanning).
Technische Details
  • Plattform: Web, Virtuelle Maschinen (Multi-VM-Topologie)
  • Sprachen: Python, Bash, HTML/CSS
