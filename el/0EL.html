Πλατφόρμα Κυβερνοασφάλειας CTF

Αυτή η διαδραστική δοκιμασία Capture The Flag (CTF) πολλαπλών σταδίων γεφυρώνει το Application Security με το Network Security σε ένα ρεαλιστικό σενάριο επίθεσης. Ολόκληρο το έργο είναι σχεδιασμένο ως ένα συμπαγές πακέτο "Infrastructure as Code": Οι φοιτητές μπορούν απλώς να κατεβάσουν την πρόκληση ως αρχείο ZIP και να την εκκινήσουν τοπικά σε ένα απομονωμένο περιβάλλον μέσω Vagrant με μία μόνο εντολή: πραγματικό plug & play χωρίς πολύπλοκες ρυθμίσεις.

Το σημείο εισόδου είναι μια custom web εφαρμογή σε Django, στην οποία πρέπει να εντοπιστούν και να αξιοποιηθούν κλασικές ευπάθειες ιστού. Η επιτυχής εκμετάλλευση (exploit) της εφαρμογής λειτουργεί ως εφαλτήριο για τη μετάβαση των παικτών στη γραμμή εντολών (CLI). Από εκεί, χρησιμοποιούν το Nmap για να αναλύσουν και να διεισδύσουν σε ένα απομονωμένο δίκτυο τριών εικονικών μηχανών (VMs). Μέσω αυτής της multi-VM τοπολογίας, ολόκληρη η υποδομή παραμένει αναπαραγώγιμη και φορητή σε οποιοδήποτε λειτουργικό σύστημα.

Τεχνικές Λεπτομέρειες
  • Πλατφόρμα: Web, Εικονικές Μηχανές (Multi-VM Topology)
  • Γλώσσες: Python, Bash, HTML/CSS
  • Framework: Django
  • Εργαλεία: Vagrant, Nmap, Git
