Cybersecurity CTF-Plattform

Μια ολοκληρωμένη πλατφόρμα Capture The Flag (CTF) σχεδιασμένη για να παρέχει προκλήσεις ασφάλειας δικτύωσης πολλαπλών σταδίων. Αυτό το έργο συνδέει την ανάπτυξη full-stack με τη μηχανική ασφάλειας (security engineering), προσφέροντας πρακτική εμπειρία στη δημιουργία ασφαλών, απομονωμένων περιβαλλόντων.

Αρχιτεκτονική & Υλοποίηση
Σχεδίασα ένα περιβάλλον δικτύου Vagrant 3-VM για την αξιόπιστη παροχή και απομόνωση προκλήσεων ασφάλειας δικτύου. Αυτή η προσέγγιση διασφαλίζει ότι οι προκλήσεις είναι αναπαραγώγιμες και ασφαλείς από παρεμβολές.

Σε επίπεδο εφαρμογής, ανέπτυξα ένα backend βασισμένο στο Django για να φιλοξενήσει και να επικυρώσει τις προκλήσεις ασφάλειας ιστού. Αυτή η εφαρμογή που βασίζεται σε REST API χειρίζεται τον έλεγχο ταυτότητας των χρηστών, την παρακολούθηση της προόδου και την επικύρωση των flags με ασφαλή τρόπο. Η πλατφόρμα προσφέρει έναν ελκυστικό και διαδραστικό τρόπο πρακτικής σε επιθετικές και αμυντικές τεχνικές ασφαλείας.

Βασικά χαρακτηριστικά και δεξιότητες:

  • Infrastructure as Code: Χρήση Vagrant και Bash για την παροχή μιας σύνθετης τοπολογίας δικτύου 3-VM για ρεαλιστικά σενάρια ασφάλειας.

  • Ανάπτυξη Full-Stack: Δημιουργία της βασικής πλατφόρμας με χρήση Python, Django, HTML και CSS, ενσωματώνοντας ένα ισχυρό backend για το χειρισμό της κατάστασης των προκλήσεων και την επικύρωση των χρηστών.

  • Μηχανική Ασφάλειας (Security Engineering): Σχεδιασμός προσαρμοσμένων προκλήσεων με εστίαση σε ευπάθειες δικτύωσης και ιστού για την προώθηση της πρακτικής μάθησης.
Τεχνικές Λεπτομέρειες
  • Πλατφόρμα: Ιστός (Web), Εικονικές Μηχανές (VM)
  • Γλώσσες: Python, Bash, HTML/CSS
  • Framework: Django
  • Εργαλεία: Vagrant, Git
