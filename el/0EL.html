Πλατφόρμα Κυβερνοασφάλειας CTF

Μια διαδραστική δοκιμασία Capture The Flag (CTF) πολλαπλών σταδίων, η οποία γεφυρώνει απρόσκοπτα το application security με το network security. Το βασικό πλεονέκτημα: Ολόκληρο το έργο είναι συσκευασμένο ως ένα compact πακέτο "Infrastructure as Code". Οι φοιτητές μπορούν απλώς να κατεβάσουν το έργο σε αρχείο ZIP, να το εκκινήσουν τοπικά μέσω Vagrant με μία μόνο εντολή και να ξεκινήσουν αμέσως.

Η Ροή της Δοκιμασίας: Από τον Ιστό στο Δίκτυο
Η πρόκληση είναι σχεδιασμένη ως ένα ρεαλιστικό σενάριο επίθεσης πολλαπλών επιπέδων:

  • Application Security (Σημείο Εισόδου): Οι παίκτες ξεκινούν από μια custom web εφαρμογή σε Django, όπου πρέπει να εντοπίσουν και να εκμεταλλευτούν κλασικές ευπάθειες ιστού.
  • Network Security (Μετάβαση): Η επιτυχής εκμετάλλευση του web app χρησιμεύει ως πύλη για τη γραμμή εντολών (CLI). Από εκεί, οι παίκτες εμβαθύνουν στο απομονωμένο δίκτυο εικονικών μηχανών (VMs), χρησιμοποιώντας το Nmap για να σαρώσουν και να παραβιάσουν τους επόμενους στόχους.

Αρχιτεκτονική & Υλοποίηση
Για την ασφαλή απομόνωση των δικτυακών προκλήσεων, σχεδίασα μια εικονική τοπολογία 3 VMs μέσω Vagrant. Αυτό διασφαλίζει ότι η υποδομή είναι πλήρως φορητή και λειτουργεί σε οποιοδήποτε λειτουργικό σύστημα χωρίς πολύπλοκες ρυθμίσεις.

Κύρια Χαρακτηριστικά:

  • Plug & Play Σχεδιασμός: Πλήρως προ-διαμορφωμένο περιβάλλον multi-VM μέσω Vagrant για άμεση εκκίνηση.
  • Full-Stack Πυρήνας: Αυτόνομη πλατφόρμα αναπτυγμένη με Python, Django, HTML και CSS για τη φιλοξενία των web security προκλήσεων.
  • Πρακτική Offensive Security: Ενισχύει την κατανόηση της αλυσιδωτής σύνδεσης ψηφιακών επιθέσεων (Web Exploitation & Network Scanning).
Τεχνικές Λεπτομέρειες
  • Πλατφόρμα: Web, Εικονικές Μηχανές (Multi-VM Topology)
  • Γλώσσες: Python, Bash, HTML/CSS
  • Framework: Django
  • Εργαλεία: Vagrant, Nmap, Git
